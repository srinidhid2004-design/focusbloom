# Curated Prompt Evidence

## Purpose

This directory keeps concise evidence of significant project instructions,
decisions, acceptance criteria, and observed results. It supports later review of
how AI-assisted work affected the project without storing full conversations.
The active milestone is the **FocusBloom Assignment 3.3 dynamic Perspective
refinement**. The five-table/11-route BreathBloom backend is retained only in
Git history and historical evidence. The nine-table/22-operation FocusBloom
backend and complete Vue interface are implemented. A narrow provider-schema
correction enabled successful live Perspective generation and explicit saves;
an instruction-only alignment then enabled the unchanged validator, bounded
read-only Garden retrieval, grounded answer, targeted deletion, and final
integrated verification.

The Canvas-ready report and final publication record preserve the distinction
between automated tests, bounded live calls, manual source review, and public
link verification.

Assignment 3.3 retains the submitted report unchanged. Its first checkpoint
separates the provider-free reviewed Alex demonstration from a one-field custom
fictional route. Prompt 13 then evaluates 15 fictional scenarios with mocks and
makes exactly four authorized live Perspective submissions for repeated/different
scenario variation. No live Garden Guide call, automatic save, retry, fallback,
or historical-evidence change occurs. Prompt 14 responds to the observed
grounding gap with a deterministic exact anchor, visible AI-draft warning, one
bounded live UI check, public clean-checkout verification, and a recording plan.

## Redaction and safety rules

- Do not include credentials, secret values, environment contents, personal
  information, research-participant information, private filesystem paths, or
  private third-party content.
- Do not paste raw chat exports. Summarize only project-relevant instructions and
  outcomes.
- Distinguish human-approved decisions, AI contributions, planned work, and
  observed results.
- Never record a planned check as passed or a mock as live evidence.
- Link only repository-safe artifacts and public-safe evidence.
